# Health Monitoring Software for Astronauts on Space Missions

Prototipo de ESP 32 para visualizar indicadores de salud y que asi los astronoutas lleguen a saber si corren algun tipo de riesgo

# Hardware y software

ESP32 con pantalla CYD
Biblioteca TFT_eSPI
Arduino / C++
